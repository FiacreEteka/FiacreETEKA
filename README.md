# Fiacre ETEKA

Étudiant en **Master 2 Recherche Opérationnelle** à l'IMSP-UAC (Bénin).
Je travaille sur l'**optimisation combinatoire** appliquée au **transport et à la logistique**, avec un intérêt pour le contexte ouest-africain.

## Axes de travail

- **Optimisation combinatoire** : tournées de véhicules (VRP), voyageur de commerce (TSP), coloration de graphes, sac à dos
- **Modélisation** : programmation linéaire et en nombres entiers (PLNE, PLNE mixte)
- **Outils** : Python, PuLP, OR-Tools, Pyomo, NetworkX, pandas
- **Prévision puis optimisation** : relier l'analyse de séries temporelles à la prise de décision logistique

## Projets phares

Ils sont réunis dans [**Projets-RO**](https://github.com/FiacreEteka/Projets-RO) :

- **Tournées de véhicules (VRP)** : 3 tournées de livraison sur 10 villes, modélisées en PLNE avec contraintes MTZ et conservation de flux
- **Distribution humanitaire après une inondation au Bénin** : PLNE mixte avec analyse de sensibilité sur le nombre de dépôts
- **Voyageur de commerce (TSP)** : formulation PLNE avec contraintes MTZ
